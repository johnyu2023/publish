债券的内在价值 ​

同一张债券，在任意时间节点，把"未来还能拿到的钱"折现到"那个时间点"的价值。它会随着剩余期限缩短和市场利率变化而动态变化。

📋 案例设定 ​

参数数值
债券面值100元
票面利率5%（每年付息5元）
付息频率每年1次
到期还本第10年末还100元本金
必要收益率（市场利率）分情景讨论

🔁 核心逻辑（记住这句话） ​

任意时点的内在价值 = 从该时点起，未来所有剩余现金流 × 对应折现因子

也就是说：

  • 第0年（刚发行）：要折现10次利息 + 1次本金
  • 第3年末：只剩7次利息 + 1次本金要折现
  • 第9年末：只剩1次利息 + 1次本金要折现

📊 情景演示：市场利率不变（5%）时，价值如何随时间收敛？ ​

假设市场利率始终=票面利率=5%，我们计算几个关键时间点的内在价值：

时间点剩余期限未来现金流内在价值计算结果
发行时（第0年）10年10次5元利息 + 100元本金5/1.05 + 5/1.05² + ... + 105/1.05¹⁰100.00元
第3年末7年7次5元利息 + 100元本金5/1.05 + ... + 105/1.05⁷100.00元
第5年末5年5次5元利息 + 100元本金5/1.05 + ... + 105/1.05⁵100.00元
第9年末1年1次5元利息 + 100元本金105/1.05100.00元

💡 结论1：当市场利率=票面利率时，债券始终按面值交易，内在价值恒为100元。这叫"平价债券"。

  • 每年你拿到的5元，只是给你的占用100元1年的利息钱。

📉 情景2：市场利率上升到7%（债券变"不值钱"了） ​

时间点剩余期限内在价值计算（折现率=7%）结果
发行时（第0年）10年5/1.07 + 5/1.07² + ... + 105/1.07¹⁰≈85.95元
第3年末7年5/1.07 + ... + 105/1.07⁷≈89.22元
第5年末5年5/1.07 + ... + 105/1.07⁵≈91.80元
第9年末1年105/1.07≈98.13元

💡 结论2：

  • 利率↑ → 折现率↑ → 内在价值↓（发行时仅值85.95元，折价14%）
  • 但随着时间推移，即使利率不变，债券价值会逐渐向面值100元收敛（这叫 "Pull to Par" 效应）
  • 因为越接近到期，不确定性越小，最后一笔105元的现值越来越接近105元本身

📈 情景3：市场利率下降到3%（债券变"更值钱"了） ​

时间点剩余期限内在价值计算（折现率=3%）结果
发行时（第0年）10年5/1.03 + ... + 105/1.03¹⁰≈117.06元
第3年末7年5/1.03 + ... + 105/1.03⁷≈114.04元
第5年末5年5/1.03 + ... + 105/1.03⁵≈109.16元
第9年末1年105/1.03≈101.94元

💡 结论3：

  • 利率↓ → 折现率↓ → 内在价值↑（发行时溢价17%）
  • 同样会随时间向100元收敛，只是从"上方"往下靠
