> Skill 就是 AI 时代的 Shell 脚本编程

## 讨论

以前操作shell的是人，以后执行的可能就是大模型了

Skill 本质就是自然语言写的 Shell，是连接 AI 大脑和系统底层的总线。
还在纠结 Prompt 优美程度的都是在玩过家家，能把 Skill 结合 Shell 跑通自动化工作流的，才是真正在搞生产力革命。
跑不起来的代码只是文本，能调动系统的 Skill 才是杠杆。

Skill 最大的价值就是脚本，这让 ai 有了手脚，从之前只能回答问题变成一个助理，这才是 skill 最大的价值😁

Skill就是AI时代的Shell脚本编程。因为有一个非常关键的因素：Skill可以调用Shell命令，所以理论上可以运行电脑上的任何程序，因此他具备电脑拥有的任何能力。所以Skill本质不是一个MD文件，而是Shell脚本程序。
