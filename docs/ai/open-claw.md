## 开源项目 OpenClaw

是的，OpenClaw 就是这个“AI 小龙虾”系列的原始源头。  你被弄糊涂的“一系列小龙虾”，其实是同一个开源项目在短短几周内三次改名的结果，不是多个不同项目。中文圈统一叫它“小龙虾”（或“大龙虾”），是因为它的吉祥物是一只可爱（又有点调皮）的龙虾——Molty（空间龙虾），象征“有爪子、能行动、会脱壳进化”。下面我用最清晰的时间线给你捋一遍来龙去脉（基于官方 GitHub、官网和多家媒体报道）：

### 1. 起源：Clawdbot（2025 年底～2026 年 1 月初）

+ 创始人：Peter Steinberger（奥地利独立开发者，PSPDFKit 公司创始人，已实现财务自由、半退休状态）。
+ 为什么叫 Clawdbot？“Claw”（龙虾/螯爪）+ “Claude-bot”的谐音（当时 Claude 是最火的大模型）。他本来只是周末随便搞的一个小工具，想通过 WhatsApp 远程操控自己电脑偷懒，结果一发到 GitHub 就爆了。
+ 这就是一切的原始源头。当时还没那么火，但已经具备核心能力：本地运行 + 聊天软件交互 + 真正执行电脑操作。

### 2. 第一次改名：Moltbot（2026 年 1 月中旬）

+ Anthropic（Claude 的公司）觉得名字太像 Claude，礼貌发邮件建议改名（避免商标纠纷）。
+ 新名字 Moltbot：Molt = 龙虾“脱壳/蜕皮”，象征项目在成长进化。吉祥物正式定为 Molty。
+ 这个阶段项目彻底爆火，GitHub 星标暴涨，硅谷开始抢 Mac Mini 部署（因为它需要一台一直开着的“专属电脑”）。

### 3. 最终定名：OpenClaw（2026 年 1 月 30 日至今）

+ 为了彻底摆脱纠纷，同时突出开源（Open） + 行动力（Claw），改成 OpenClaw。
+ GitHub 仓库也正式从之前的名字改为 openclaw/openclaw。
+ 现在官网 openclaw.ai、所有教程、插件生态都用这个名字。

### 它到底是什么？为什么这么火？

+ 不是普通聊天机器人，而是真正的 AI Agent（智能体），被称为“Large Action Model（大型行动模型）”。
+ 核心特点：
  + 跑在你自己电脑上（Mac/Windows/Linux，甚至旧手机都行），数据本地优先，隐私好。
  + 通过你已经用的聊天软件交互（Telegram、WhatsApp、飞书、Discord、Signal 等）。
  + 能真正干活：清邮箱、整理文件、发邮件、管理日历、订机票、浏览器自动操作、执行代码、写文档、24/7 主动执行定时任务……
  + 支持任意大模型（Claude、GPT、Gemini、DeepSeek、Ollama 本地模型都行）。
  + 有持久记忆、社区技能插件（ClawHub），AI 甚至能自己写新技能。

+ 为什么 2026 年初直接封神？开源 + 门槛低 + “真的能用”三连击。之前 Agent 要么贵、要么难部署、要么只能聊天，这只龙虾把三者都解决了。短短两周 GitHub 就 10 万+ 星标（现在更多），被称作“最接近大众对智能体想象的产品”。

### 当前状态（2026 年 2 月底）

+ 创始人 Peter Steinberger 已加入 OpenAI（2 月中宣布），但 OpenClaw 项目转为基金会形式独立运营，继续完全开源、社区驱动。
+ 生态超级活跃：各种中文优化版、一键部署（Zeabur、阿里云等）、记忆增强插件、甚至接机器人硬件（Vbot）。
+ 注意事项：因为权限高，建议用虚拟机或专用老电脑跑，设置好 API 用量上限和安全白名单。

## 展望未来

+ 它验证的模式——"本地编排 + 云端推理 + 持久记忆 + 多渠道接入"——这个范式是确定的。接下来会看到更多类似产品，包括大厂的（Claude Cowork 已经在做了）。
+ 对开发者来说，真正值得学的不是 OpenClaw 本身，而是它背后的设计哲学：
  + 模型是可替换的，记忆才是核心资产
  + Markdown 是最好的 LLM 配置语言
  + 混合搜索（向量 + 关键词）比纯向量搜索靠谱得多
  + 够用就好，SQLite 能解决的问题不要上 Postgres
  + 
+ 未来此类代理将重塑企业运营，但安全与监管是核心挑战。

## 一种思考（借鉴）

OpenClaw 最好只作为一种模式参考，不建议照搬为企业级应用，对于企业来讲应该构建一个基于 AI 能力的“操作系统”，将组织内部沉淀的 SOP 、最佳实践和制度知识等内容转化为数字资产，建立 AI 技能库和流水线，用倒推的逻辑建立一种新的管理范式，将结果交付给管理层。
