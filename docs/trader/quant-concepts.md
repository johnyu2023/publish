## 冷热路径

> 冷热路径 - 区分Level-2数据中两种截然不同的推送机制

+ 热路径（Hot Path） - 指“逐笔数据”，代表“事件驱动”，一有风吹草动就立刻上报
+ 冷路径（Cold Path）- 指“快照数据”，代表“时间驱动”，到了时间点才汇总报告一次

### 对比表格

| 维度 | 🔥 热路径 (Hot Path) | ❄️ 冷路径 (Cold Path) |
| :--- | :--- | :--- |
| **核心比喻** | **逐笔流水账** | **定时快照/切片** |
| **对应数据** | 逐笔成交、逐笔委托 | 十档盘口快照 (Level-2)，五档盘口快照 (Level-1) |
| **触发机制** | **事件驱动**：市场上每发生一笔成交或一笔委托，就立即推送一条数据。 | **时间驱动/切片**：交易所按固定频率（如A股主板通常为**3秒**一次）生成一张当时的“快照”。 |
| **数据特点** | **极其轻量、实时、量大**：完整记录市场每一个微观动作，单日数据量可达数十GB。 | **静态、聚合、量小**：只记录这3秒内的**起始和最终状态**，不展示中间过程。例如，Level-1的“分笔成交”实际上是这3秒内成交量和最后一笔价格的汇总。 |
| **数据精度** | 毫秒/微秒级，真实还原交易过程。 | 秒级（3秒），只看到一个时间点的截面。 |
| **能看到什么** | 能看到一笔1000手的大单是被谁、分几次、以什么价格买走的。 | 只能看到这3秒内总共成交了1000手，但看不出具体细节。 |

### 冷热数据的用途

+ **看见“主力行踪”**：只有“热路径”的逐笔数据，才能帮你还原主力资金真实的挂单、撤单和成交痕迹。比如，通过逐笔委托可以发现主力在买一价位挂了1万手，但又在下一秒撤单——这种“虚假订单”在3秒一次的“冷路径”快照里是看不出来的。

+ **识破“虚假盘口”**：普通的十档快照（冷路径）只能告诉你现在买一有1000手挂着。而逐笔委托（热路径）能告诉你这1000手是1个大户挂的，还是1000个小散户挂的。前者可能是支撑，后者可能是陷阱。
