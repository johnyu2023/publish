## 现代投资组合理论（MPT）

+ 提出者：哈里·马科维茨
+ 核心思想：投资者不应孤立地看一只股票的风险和收益，而应**关注整个投资组合的风险-收益特征**。通过将不同资产组合在一起，可以在不降低预期收益的情况下降低整体风险。

### 均值-方差模型

> `均值-方差模型`是`投资组合理论`的标准数学模型，它告诉投资者如何根据`收益（均值）` 和`风险（方差）`这两个指标，来选择最合适的资产组合。

+ **收益**：组合的预期收益是各资产收益的**加权平均值**。
+ **风险**：组合的风险（方差，σ²）**不是**各资产风险的加权平均，因为资产之间的**相关性（ρ）** 会起作用。
  + 如果资产之间**不完全正相关**（ρ < 1），组合的风险会低于单个资产风险的加权和。
  + 这就是**分散化**的根本原理：**不要把鸡蛋放在同一个篮子里**。

+ **数学形式（简化）**：

两个资产的情况：

+ 组合预期收益：$E(R_p) = w_1 E(R_1) + w_2 E(R_2)$
+ 组合方差：$\sigma_p^2 = w_1^2 \sigma_1^2 + w_2^2 \sigma_2^2 + 2w_1 w_2 \rho_{12} \sigma_1 \sigma_2$

当 $\rho_{12} < 1$ 时，$\sigma_p^2$ 会小于各资产方差的加权和。

### 投资组合理论的核心缺陷

#### 缺陷1：风险只用方差/标准差衡量

**问题**：标准差同时把**上涨波动**和**下跌波动**都视为风险。

但投资者真正害怕的是**下跌**（亏损），而不是上涨。一个资产如果经常大涨大跌，标准差会很大，但在投资实践中，向上的波动并不被大多数投资者视为“风险”。

**后果**：MPT会把一些实际上投资者喜欢的特征（高上行的弹性）当成风险来处理。

#### 缺陷2：假设收益服从正态分布

**问题**：MPT的核心推导依赖于收益率呈**正态分布**（钟形曲线）。

但金融市场的真实数据中，**极端事件（肥尾）**比正态分布要多得多：

+ 市场崩盘（如2008年、2020年3月）
+ 暴涨行情

正态分布会严重低估这类极端事件的概率。

**后果**：用MPT构建的组合，可能在99%的时间里看着很安全，但那个1%的尾部事件一来，就会远超模型的预估损失（比如长期资本管理公司的倒闭）。

#### 缺陷3：依赖历史数据来估计未来

**问题**：MPT需要输入三个核心参数：

+ 各资产的预期收益
+ 各资产的风险（标准差）
+ 资产之间的相关性

但这些参数都是用**历史数据**推算的。而**历史不代表未来**：收益、波动、相关性都会随时间变化。

**后果**：**Garbage in, garbage out**。如果输入的参数是错的（这在现实中几乎是必然的），输出的有效前沿也会失效。

> 一个经典的批评：雷曼兄弟破产前，用前5年的数据算出来的风险很低，因为那段时期恰好是低波动期。

#### 缺陷4：不区分系统性风险和非系统性风险

**问题**：MPT把所有的风险（总方差）都当作需要管理的对象，但没有明确指出：

+ 哪部分风险可以通过分散化来**消除**（非系统性风险）
+ 哪部分风险**无法消除**，只能承担（系统性风险）

#### 缺陷5：假设投资者是纯粹理性的

**问题**：MPT假设投资者：

+ 完全理性
+ 只有两个目标：最大化收益、最小化风险
+ 信息完全对称
+ 没有交易成本、没有税收

在现实中：

+ 投资者有**行为偏差**（过度自信、损失厌恶、从众心理等）
+ 有交易费用、流动性限制、税收
+ 不同投资者的风险偏好不是简单的均值-方差优化能表达的

#### 缺陷6：忽略时间维度

**问题**：MPT是**单期模型**（比如一年），不考虑资金进出、现金流的时序。

但实际投资中：

+ 养老基金有长期的支付义务
+ 投资者可能有不同的投资期限
+ 不同时点的风险承受能力不同

## 资产预期收益率

### 知识点一：单个资产预期收益率 (Expected Return)

**核心理解：** 未来的市场是千变万化的，单只股票在不同市场行情下有不同的收益率。我们要结合每种行情发生的“概率”，算出一个加权平均值，这就是它综合来看的预期收益率。

**公式：**

$$E(R) = p_1R_1 + p_2R_2 + ... + p_nR_n$$

**小例子：**
假设你正在分析一只重点关注的股票 A，经过你的预测，未来一年它面临三种可能的市场情形：

+ **情形1（牛市）：** 发生的概率 $p_1$ 是 30%，这种情形下股票A的收益率 $R_1$ 是 20%。
+ **情形2（震荡市）：** 发生的概率 $p_2$ 是 50%，此时股票A的收益率 $R_2$ 是 8%。
+ **情形3（熊市）：** 发生的概率 $p_3$ 是 20%，此时股票A的收益率 $R_3$ 是 -10%（也就是亏损 10%）。

**计算过程：**
将概率和对应的收益率相乘，然后全部加起来：

$$E(R_A) = (0.30 \times 0.20) + (0.50 \times 0.08) + (0.20 \times -0.10)$$

$$E(R_A) = 0.06 + 0.04 - 0.02 = 0.08$$

**结论：** 综合考虑各种市场情况后，股票 A 的预期收益率是 **8%**。

---

### 知识点二：资产组合的期望收益率 (Portfolio Expected Return)

**核心理解：** 当你买入不止一只股票时，你的总收益率取决于每只股票自己的预期收益率，以及你分配给它们的“仓位权重”（即这只股票占你总资金的百分比）。

**公式：**

$$E(R_p) = w_1E(R_1) + w_2E(R_2) + ... + w_nE(R_n)$$

**小例子：**
现在你不仅有股票 A，还看中了股票 B。你打算构建一个简单的双股票投资组合：

+ **资产1（股票 A）：** 刚才算出来它的预期收益率 $E(R_1)$ 是 8%。你打算把总资金的 60% 买入它（仓位权重 $w_1$ = 0.60）。
+ **资产2（股票 B）：** 经过评估，股票 B 的预期收益率 $E(R_2)$ 是 15%。你用剩下的 40% 资金买入它（仓位权重 $w_2$ = 0.40）。

**计算过程：**
将每只股票的仓位权重乘上它自己的预期收益率，然后相加：

$$E(R_p) = (0.60 \times 0.08) + (0.40 \times 0.15)$$

$$E(R_p) = 0.048 + 0.06 = 0.108$$

**结论：** 这个由 60% 股票 A 和 40% 股票 B 构成的投资组合，其整体的期望收益率是 **10.8%**。

## 资产的风险

### 单个资产的方差和标准差

> 在投资中，收益和风险是硬币的两面。如果说“预期收益率”衡量的是你**平均能赚多少钱**，那么“方差”和“标准差”衡量的就是你**赚钱的确定性有多高**（也就是收益率上下波动的幅度有多大）。

例子 3：回到我们上次的“股票 A”

为了让你更有连贯性，我们用你之前熟悉的“股票 A”再算一遍风险。

**之前“股票 A”的数据记录：**

+ **情形1（牛市 30%）：** 收益 20%
+ **情形2（震荡市 50%）：** 收益 8%
+ **情形3（熊市 20%）：** 亏损 -10%
+ **上次算出的预期收益率 $E(R)$： 8% (也就是 0.08)**

我们来算算这只股票的“波动率”（标准差）有多大：

**1. 计算方差 ($\sigma^2$)：**

$$\sigma^2 = 0.30 \times (0.20 - 0.08)^2 + 0.50 \times (0.08 - 0.08)^2 + 0.20 \times (-0.10 - 0.08)^2$$

$$\sigma^2 = 0.30 \times (0.12)^2 + 0.50 \times (0)^2 + 0.20 \times (-0.18)^2$$

$$\sigma^2 = 0.30 \times 0.0144 + 0 + 0.20 \times 0.0324$$

$$\sigma^2 = 0.00432 + 0.00648 = 0.0108$$

**2. 计算标准差 ($\sigma$)：**

$$\sigma = \sqrt{0.0108} \approx 0.1039 = 10.39\%$$

**业务结论：**
股票 A 的预期收益率是 **8%**，但它的标准差（风险波动率）达到了 **10.39%**。这意味着买入股票 A，你平时面临的波动幅度其实比你期望赚到的钱还要大，这是一只具有一定风险波动的股票。

### `方差`和`标准差`的意义

> **方差是为了服务于“数学公式”，而标准差是为了服务于“人类直觉”。**
>
> + **方差（$\sigma^2$）** 就像是厨房里还没做熟的**半成品食材**。它在后厨（数学推导、计算机建模）被厨师们切配、组合、翻炒，因为它的形态最适合加工。
> + **标准差（$\sigma$）** 就像是最后端上桌的**精美菜肴**。它经过了开根号（摆盘），变成了顾客（投资者、业务员）能直接理解、消化和品尝的样子。

#### 1. 单位问题：标准差是给“人”看的（为了直观业务理解）

计算方差的公式里，最核心的一步是**把偏差值“平方”**。这一平方，虽然消除了正负号，但也把**单位**给平方了。

+ **单位错位：** 假设你买了一只股票，预期能赚 10 块钱。如果你算出来的方差是 25，这个 25 的单位是什么呢？是 **“25个平方块钱”**。或者在收益率里，单位变成了 **“百分比的平方”**。
+ **人类无法理解“平方单位”：** 你可以在现实中找到“10块钱”，但你绝对想象不出“1平方块钱”长什么样。在给老板或客户汇报风险时，你如果说“这只股票的风险是 0.006 个平方收益率”，别人完全听不懂。
+ **标准差的意义（还原单位）：** 所以，我们要对方差开根号，把“平方块钱”还原回“块钱”，把“百分比的平方”还原回“百分比”。算出来标准差是 7.75%，你就可以直观地说：“这只股票平均赚 80%，但上下会有大概 7.75% 的浮动。”**标准差和预期收益率在同一个“次元”里，人类大脑才能直观比较。**

#### 2. 数学属性：方差是给“公式”用的（为了方便推导和计算）

既然标准差这么直观，那我们干脆抛弃方差，直接用绝对值来表示偏离程度不就行了（比如直接算 $|实际 - 预期|$）？这就是方差存在的第二个绝对理由：**它的数学性质太好了。**

+ **微积分的宠儿：** 在高等数学和金融工程里，为了找到“风险最小”的投资组合，我们需要对公式求导找极值点。绝对值函数（折线）在拐点处是没法求导的，而平方函数（抛物线）极其平滑，求导非常容易。
+ **方差具备“可加性”：** 这是在投资组合理论中最重要的一点！如果资产 A 和资产 B 是完全独立的，那么它们组合在一起的**总方差 = A的方差 + B的方差**。
+ 但是，**标准差不能直接相加！** ( $\sqrt{a+b} \neq \sqrt{a} + \sqrt{b}$ )。

+ **方差的意义：** 当我们在构建包含几十只股票的大型投资组合、跑计算机模型（比如大名鼎鼎的马科维茨投资组合理论）时，中间的所有加减乘除推导，**全部都是用方差来完成的**，因为只有方差能直接套用严谨的数学代数运算。

## 资产收益的相关性

+ 主要使用`协方差`和`相关系数`这两个指标来测度两个风险资产收益之间的相关性
+ 在量化投研和资产配置的语境下，协方差和相关系数是衡量资产之间如何“同频共振”或“背道而驰”的核心指标，它们直接决定了投资组合的风险水平。

### 1. 投资视角下的“协方差” (Covariance)

在金融中，协方差衡量的是两项资产**收益率**的协同波动方向和绝对规模。

+ **金融含义：**
+ **正协方差 ($Cov > 0$)：** “同涨同跌”。例如，两只同属新能源赛道的股票，或者大盘宽基指数基金与某只蓝筹股，它们往往在同一市场环境下录得同向的收益。
+ **负协方差 ($Cov < 0$)：** “跷跷板效应”。例如，股市大跌时，避险情绪往往推高国债价格。股票资产与高信用等级债券之间常常呈现负协方差。这种特性是构建**对冲策略**和降低底仓风险的基石。

+ **量化应用：计算投资组合的总风险 (方差)**
这是协方差在金融工程中最核心的用途（马科维茨的现代资产组合理论）。一个由资产 A 和 B 组成的投资组合，其整体风险（方差）的公式为：

$$Var(Port) = W_A^2 \cdot Var(R_A) + W_B^2 \cdot Var(R_B) + 2 \cdot W_A \cdot W_B \cdot Cov(R_A, R_B)$$

*(其中 $W$ 代表资金权重)*
从公式可以看出，**如果协方差为负，组合的总风险会直接降低**。这就是“不要把鸡蛋放在同一个篮子里”的数学证明。

+ **金融语境下的局限：** 协方差的单位是“收益率的平方”（例如 $\%{^2}$），这是一个在直觉上极难理解的数字（比如协方差是 $0.0004$），你很难据此直接判断两只股票联动的紧密程度。

---

### 2. 投资视角下的“相关系数” (Correlation Coefficient)

为了解决协方差难以直观评估的问题，我们使用相关系数（$\rho$ 或 $r$）。在金融数据分析中，它将协方差“标准化”到了 $[-1, 1]$ 的区间。

数学上，它连接了协方差和两项资产的**波动率**（标准差 $\sigma$）：

$$Cov(R_A, R_B) = \rho \cdot \sigma_A \cdot \sigma_B$$

+ **金融含义与量化实战：**
+ **$\rho \approx 1$ (高度正相关)：** 两项资产走势高度趋同（例如两只跟踪沪深300的ETF）。**实战意义：** 在多因子选股模型中，如果两个因子（如市盈率PE和市净率PB）高度正相关，会引发“多重共线性”问题，导致模型失真，通常需要进行因子正交化处理或剔除其一。
+ **$\rho \approx 0$ (零相关/低相关)：** 两项资产的涨跌互不干扰（例如 A股股票 与 某种特定的商品期货）。**实战意义：** 这是资产配置的最爱。寻找低相关的资产加入组合，可以在不牺牲预期收益的情况下，有效平滑资金曲线的净值波动。
+ **$\rho \approx -1$ (高度负相关)：** 一项资产大涨，另一项必然大跌。**实战意义：** 极其罕见但极具价值，通常用于构建无风险套利策略或进行精准的风险敞口对冲（例如做多某只股票的同时，做空与它高度相关的同行业股票，即统计套利中的“配对交易 Pair Trading”）。

## 风险平价策略

+ `风险平价`是对英文 `Risk Parity` 的翻译。

  + Risk（风险）：指的是投资中资产价格的波动性（通常用标准差衡量）。波动越大，风险越高。
  + Parity（平价/相等）：这个词源自经济学，比如“购买力平价”，意思就是“在某个维度上相等”。在金融里，“平价”意味着`权重相等、地位平等`。
  + Risk Parity 就是：让不同资产所承担的风险权重达到平等地位。

+ 核心意思：平均分配风险，而不是资金

## 可持续投资

> 将企业的**可持续发展**纳入**投资决策**，目标是**财务回报**与**社会、环境效益**的平衡。

+ 核心非财务因素：ESG

  + **E（环境）**：碳排放、污染、资源利用、生物多样性  
  + **S（社会）**：员工权益、客户安全、社区关系、数据隐私  
  + **G（治理）**：董事会结构、反腐、股东权利、薪酬公平

+ ESG三因素的关联性

  + **并非完全独立，而是相互交织、互为影响**
  + **薄弱的公司治理（G 差）** → 导致企业**在环境保护（E）和社会责任（S）方面投入不足、管理缺失**
