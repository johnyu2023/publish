## 资产负债表

- 资产负债表反映企业在**特定日期**的财务状况，其基本结构遵循会计恒等式：**资产 = 负债 + 所有者权益**

- 大类：
  - 资产（按流动性排列）
    - 流动资产 （预计在一年内或一个营业周期内变现、出售或耗用）
    - 非流动资产 （超过一年变现或使用）
  - 负债（按偿还期限排列）
    - 流动负债 （一年内或一个营业周期内需偿还）
    - 非流动负债 （偿还期超过一年）
  - 所有者权益（或股东权益）
    - 实收资本（或股本）  
    - 资本公积  
    - 其他综合收益  
    - 盈余公积  
    - 未分配利润

## 企业偿债能力

### 1. 资产负债率

- **公式**：资产负债率 = 总负债 ÷ 总资产 × 100%
- **含义**：反映总资产中有多大比例是靠负债形成的。比率越高，债权人风险越大。

### 2. 负债权益比（又称产权比率、债务股权比率）

- **公式**：负债权益比 = 总负债 ÷ 股东权益
- **含义**：直接反映债权人权益与所有者权益的相对关系。值越大，财务杠杆越高。

### 3. 权益乘数

- **公式**：权益乘数 = 总资产 ÷ 股东权益
- **含义**：反映每1元股东权益控制的总资产倍数。乘数越大，杠杆越高。

### 简单记忆

- **资产负债率**：总负债 / 总资产（百分比）
- **负债权益比**：总负债 / 股东权益（倍数）
- **权益乘数**：总资产 / 股东权益（倍数）

> 三者同向变动：负债率越高 → 负债权益比越高 → 权益乘数越大 → 杠杆越高。

## 企业盈利能力

### 公式

- 销售利润率 = 净利润 ÷ 销售收入
- 资产收益率 = 净利润 ÷ 总资产
- 净资产收益率 = 净利润 ÷ 所有者权益

### `总资产收益率`和`净资产收益率`

\[
（总）资产收益率: ROA = \frac{\text{净利润}}{\text{总资产}}
\]
\[
净资产收益率： ROE = \frac{\text{净利润}}{\text{所有者权益}}
\]

两者唯一的区别就是**分母不同**：

- ROA 的分母 = 总资产（别人的钱 + 自己的钱）
- ROE 的分母 = 所有者权益（只有自己的钱） - 也就是 `总资产 - 负债`
- \( ROE = ROA \times \text{权益乘数} \)

---

### 例题解析

- 某企业的总资产收益率是20%，若资产负债率也为20%，求净资产收益率（ROE）

- 解答

\[
ROE = \frac{\text{净利润}}{\text{所有者权益}}
\]

- 第一步：分子分母同时 ÷ 总资产

\[
ROE = \frac{\text{净利润} \div \text{总资产}}{\text{所有者权益} \div \text{总资产}} = \frac{\text{ROA}}{\text{所有者权益} \div \text{总资产}}
\]

- 分子已知，算分母

\[
\frac{\text{所有者权益}}{\text{总资产}} = \frac{\text{总资产-负债}}{\text{总资产}} = 1- \frac{\text{负债}}{\text{总资产}} = 1 - 总资产负债率 = 1 - 0.2 = 0.8
\]

- 总的计算

\[
ROE = \frac{\text{ROA}}{\text{0.8}} = \frac{\text{0.2}}{\text{0.8}} = 0.25
\]

## 风险指标 β 系数

> β 系数（Beta）是衡量一项资产（或投资组合）相对于整个市场（基准，如沪深300）系统性风险的指标。

### β 系数值的意义

- **β = 1**：与市场同涨同跌，风险相同。
- **β > 1**：比市场波动更大（如 β=1.5，市场涨1%，它平均涨1.5%）。
- **β < 1**：比市场波动更小（如 β=0.5，较稳定）。
- **β = 0**：与市场无关（如无风险资产）。
- **β < 0**：与市场反向变动（较少见，如某些避险资产）。

### 如何比较

- β系数比较的前提是两者使用同一个市场基准

### β系数的核心用途

- 衡量单个资产/组合相对市场的系统性风险
- 比较两个投资组合的风险水平
- 计算投资组合的必要收益率（CAPM模型）

\[
\text{预期收益率} = R_f + \beta \times (R_m - R_f)
\]
用于资产定价和投资决策。

### 和其他风险概念的对比

| 指标 | 衡量什么 | 对应风险类型 | 是否可分散 |
| :--- | :--- | :--- | :--- |
| **贝塔（β）** | 与**市场**波动的对比 | **系统风险** | **不可分散** |
| **阿尔法（α）** | 基金经理超越市场波动的超额收益 | （不是风险，是能力） | — |
| **标准差（σ）** | 基金自身总体的波动大小 | **总风险**（系统+非系统） | 包含可分散部分 |
| **夏普比率** | 每单位**总风险**（用标准差）获得的超额回报 | 总风险调整后收益 | — |

**重点：** 即使一只基金的标准差（总波动）很大，但如果这个波动和“大盘”关系不大（比如因为某只重仓股自己出了问题），那么它的贝塔可能并不高。因为贝塔**过滤掉**了那些可分散的、和整体市场无关的波动。

## 即期远期

### 概念

- “即期”代表“现在、马上交割”，“远期”代表“现在约定、未来交割”。

- 核心概念总结：即期 vs 远期（适用于任何资产）

| 概念 | 核心要素 | 交易发生时间 | 资金/资产交割时间 |
| :--- | :--- | :--- | :--- |
| **即期交易** | **“一手交钱，一手交货”** | **现在** | **现在**（或按市场惯例，如外汇的T+2） |
| **远期交易** | **“现在签约，未来履约”** | **现在**（签订合约） | **未来**（约定的到期日） |
