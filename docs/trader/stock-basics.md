## 总股本

> 总股本 是指一家公司所有已发行的`股票总数`。简单说，就是公司把它的“所有权”分成了多少份。

### 概念比较

| 概念 | 核心含义 | 性质 | 常用别名 | 例子 |
| :--- | :--- | :--- | :--- | :--- |
| **股本总额** | **钱的总数** (资本总量) | **价值量** (元) | 注册资本、实收资本 | 5亿元 |
| **总股本** | **份的总数** (股票数量) | **数量** (股) | 股份总数 | 5亿股 |

**它们的关系是：**
> **股本总额 (元) = 总股本 (股) × 股票面值 (元/股)**

在中国，大部分股票的面值是 **1元/股**，所以数字上两者相等（5亿元 = 5亿股 × 1元）。这是造成混淆的最大原因！

- 当你听到 **“公司股本很大”** → 指的是 **资本总量**（钱多）。
- 当你看到 **“总股本为10亿股”** → 指的是 **股票数量**（份多）。
- 当你计算 **市盈率、每股收益** 时 → 心里想的应该是 **股票数量**（用总股本或流通股本）。

### 不同类型股票和总股本的关系

| 股票类型 | 是否计入<br>**已发行股本**？ | 是否计入<br>**流通在外股本**？ | 说明 |
| :--- | :---: | :---: | :--- |
| **普通股** | ✅ 是 | ✅ 是 | 标准股份 |
| **优先股** | ✅ 是 | ✅ 是 | 属于已发行股本，但在计算普通股每股收益时被剔除 |
| **限制性股票** | ✅ 是 | ⚠️ 视条件 | 已发行，但在限售期内流通受限 |
| **库存股** | ✅ 是 | ❌ 否 | **这就是关键错误所在**：它属于**已发行股本**，但**不属于流通在外股本** |

### 一句话总结
> **总股本 = 公司发行的所有股票（普通股+优先股+…），而流通在外股本 = 总股本 - 库存股。**  
> 你平时看到的股价、市盈率、每股收益，本质上都是基于 **流通在外股本**（或其加权平均）计算的。

## 市盈率

### 公式

\[
\text{市盈率} = \frac{\text{每股股价}}{\text{每股收益}}
\]  

或者直接：

\[
\text{市盈率} = \frac{\text{公司总市值}}{\text{归属于母公司所有者的净利润}}
\]

- 总市值 = 股价 × **流通在外股本**

### 解读

- 市盈率代表的是市场对这家公司的“赚钱能力”所给出的“价格标签”
- 最直观的理解：回本年数 - 假设一家公司的利润永远不变，并且把所有利润都分给股东，那么你需要持有多少年，才能通过利润收回你购买股票投入的本金。
- 更深刻的含义：市场对公司的“情绪”和“预期”
  - 你会发现好公司的市盈率往往都很高，比如30倍、50倍甚至更高。
  - 高市盈率实际上反映了**市场对公司未来高速增长的强烈预期**。
